安裝方式

擇一即可。所有方式都使用你自己的免費 Apple ID,安裝的對象是 未簽署 IPA;簽章由你的裝置端工具或 Xcode 完成。

1. AltStore(來源饋流,需 Mac/PC 配套)

  1. 在 Mac 或 Windows 安裝 AltStore 與 AltServer。
  2. 以 USB 連接 iPhone,從 AltServer 選單選擇 Install AltStore,輸入你的免費 Apple ID。
  3. iPhone:設定 → 一般 → VPN 與裝置管理 → 信任你的開發者描述檔。
  4. AltStore → Sources(來源)→ 右上角「+」→ 貼上下方來源 URL。
  5. 在來源中找到 HK 3D 網格 → Install,再次輸入同一免費 Apple ID。
  6. 讓 AltServer 與 iPhone 保持同一 Wi-Fi;AltStore 會在背景重新簽署,更新 7 天憑證。

來源 URL:

https://mcc-mak.github.io/ios-app/apps.json

2. SideStore(來源饋流,設定後無線)

  1. 依 SideStore 官方文件完成一次性電腦設定(配對檔 + StosVPN),把 SideStore 安裝到 iPhone。
  2. iPhone:設定 → 一般 → VPN 與裝置管理 → 信任 SideStore 的開發者描述檔。
  3. SideStore → Sources → 「+」→ 貼上與上方相同的來源 URL。
  4. 選擇 HK 3D 網格 → Install,以免費 Apple ID 簽署。
  5. 保持 SideStore 在背景執行;它會透過裝置端服務重新整理憑證,無需電腦。

SideStore 與 AltStore 共用同一個 apps.json 饋流,版本與下載連結完全一致。

3. Sideloadly(Windows/macOS,最直接)

  1. 從本頁或 發行版本頁面下載最新 .ipa。
  2. 安裝 Sideloadly(Windows 需先安裝 iTunes)。
  3. USB 連接 iPhone,在 Sideloadly 選擇裝置,輸入你的免費 Apple ID。
  4. 把 .ipa 拖進視窗 → Start,等待簽署與安裝完成。
  5. iPhone:設定 → 一般 → VPN 與裝置管理 → 信任你的 Apple ID。
  6. 7 天內重新執行一次側載,即可延長使用期限。

4. Xcode 直接安裝(開發者,自行簽署)

  1. 以 Unity 匯出 iOS Xcode 專案(本機 Tuanjie/Unity + iOS Build Support 模組)。
  2. 開啟匯出的 .xcodeproj,目標 → Signing & Capabilities → Team 選擇你的 Personal Team(免費 Apple ID)。
  3. 以 USB 連接 iPhone,在執行目標選擇該裝置 → Run。
  4. iPhone:設定 → 一般 → VPN 與裝置管理 → 信任開發者。
  5. 7 天後在 Xcode 重新 Run,或改用 AltStore/SideStore 自動更新。

注意:管線產出的 IPA 是未簽署的,不能直接安裝;此路徑由 Xcode 以你的免費帳號重新簽署。Unity 專案位於 codebase/unity-project/。

5. GitHub Actions 成品(開發者驗證)

  1. 登入 GitHub → Actions → 零機密 iOS 管線。
  2. 選擇 main 或標籤的執行,捲到頁面底部 Artifacts。
  3. 下載 unsigned-ipa → 解壓取得 .ipa 與 manifest.json。
  4. 以 Sideloadly 或 AltStore 安裝(需登入 GitHub,成品保留 30 天)。

Actions 成品是暫時性的,不會進入 apps.json; 長期分享請使用 GitHub Release(推送 v* 標籤)。

常見問題

為什麼之前顯示「尚無發行版本」?

入口網站不保存 IPA,也不讀取 CI 成品。它只讀 apps.json,而 apps.json 由 generate_apps_json.sh 依最新 GitHub Release 產生。 如果儲存庫從未推送 v* 標籤,就沒有 Release,饋流的 apps 自然是空的 —— 即使 Actions 裡已經成功建置出 IPA。

修正方式:推送一個語意化版本標籤(例如 v1.3.0)。管線的 release:ipa 會建立 Release 並附上 .ipa、.dSYM.zip、 manifest.json;接著 deploy:docs 重新產生 apps.json,版本就會出現在本頁。

IPA 要去哪裡下載?

三個地方,依穩定性排序:

  1. 最新發行版本 —— 永久連結,AltStore/SideStore 也指向這裡。
  2. 本頁最上方的下載按鈕 —— 由 apps.json 提供直接資產連結。
  3. Actions → build:ipa → unsigned-ipa 成品 —— 暫時性,需登入,保留 30 天。
App 顯示「未受信任的開發者」怎麼辦?

首次開啟前,到 iPhone 的設定 → 一般 → VPN 與裝置管理,點按你的 Apple ID 或開發者描述檔, 選擇「信任」。若看不到描述檔,先開啟一次 App 再回到此頁。

為什麼 7 天後 App 打不開?

免費 Apple ID 的簽署憑證只有 7 天效期,到期後 iOS 會拒絕啟動。這不是 App 損壞, 重新簽署即可:AltStore/SideStore 在背景自動更新,或 7 天內用 Sideloadly/Xcode 重新安裝。 付費開發者帳號(每年 99 美元)才能延長至一年,本專案刻意不使用。

需要付費 Apple 開發者帳號、憑證或描述檔嗎?

不需要。管線只使用內建 GITHUB_TOKEN,不保存任何 Apple 機密;每次 xcodebuild 都以未簽署旗標執行。簽章完全發生在你的裝置或本機 Xcode。

有什麼數量限制?

每台裝置最多 3 個側載 App;每個免費 Apple ID 每 7 天最多註冊 10 個 App ID。若安裝失敗並提示達到上限,先移除不用的側載 App 或等待重置。

AltStore 找不到來源或無法更新?

確認 https://mcc-mak.github.io/ios-app/apps.json 可在 Safari 開啟且為合法 JSON; 確認 AltServer 與 iPhone 在同一 Wi-Fi;必要時在 AltStore 的 Sources 頁面下拉重新整理。 SideStore 則需保持 StosVPN 連線。

管線

單一工作流程 cicd.yml,四個 job 依序執行;job 顯示名稱固定為 階段:產物:

  1. test:sastiOS 模擬器單元/UI 測試、覆蓋率、CodeQL Swift 靜態分析(未簽署)
  2. build:ipaRelease 未簽署封存 → Payload/<App>.app 位於 zip 根目錄的 IPA + .dSYM.zip + manifest.json
  3. release:ipa僅 v* 標籤:建立 GitHub Release,附加 IPA、dSYM、manifest
  4. deploy:docs部署本頁,並由最新 Release 重新產生 apps.json 饋流
觸發行為
push 至 main測試 → 建置 → 部署入口網站
push 標籤 v*測試 → 建置 → 發行 → 部署(完整鏈)
pull request測試 → 建置(不發行、不部署)
每日排程未簽署建置健康檢查(偵測 runner/Xcode 漂移)
手動Run workflow,依所選 ref 執行

零 Apple 機密;所有 xcodebuild 皆帶 CODE_SIGNING_ALLOWED=NO CODE_SIGNING_REQUIRED=NO CODE_SIGN_IDENTITY="" CODE_SIGN_ENTITLEMENTS=""。 詳見 cicd.yml 與 CI/CD 文件。
